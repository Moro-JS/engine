# @morojs/engine 1.1.21

A documentation release. The engine's source is unchanged: no export or
capability flag is added, removed or renamed, and nothing on the wire
changes. Update whenever convenient.

## README

- The package README says what the engine serves: HTTP/1.1, HTTP/2 and
  WebSocket (with permessage-deflate), with TLS terminated in-process.
- The MoroJS configuration sample no longer lists `engine: 'uws'`. MoroJS
  removed uWebSockets.js in 1.8.24; the values are `'moro'` (the default)
  and `'node'`.
- The repository README opens on what the engine is and why it exists. The
  release-by-release history it carried lives in
  [CHANGELOG.md](../CHANGELOG.md).

## Roadmap

`docs/ROADMAP.md` no longer lists as pending what has shipped: the Windows
(MSVC) build and CI legs, and the connection and time limits
(`maxConnections`, `requestTimeoutMs`, `responseTimeoutMs`).

## Package

npm keywords gain `http2`, `websocket` and `tls`.
